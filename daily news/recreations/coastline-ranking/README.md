# Coastline ranking / green-globe recreation

This is an original 60-second editorial recreation of the supplied Short’s
countdown premise. It keeps the fast five-country structure, but uses the
daily news green globe: parchment/sage atlas texture, country locks, finite
map-library annotations, source rails, and a final takeaway card. It does not
reuse the reference channel’s logo, flags, footage, or frame-by-frame edit.

Build from the daily news project root:

```sh
node recreations/coastline-ranking/build.mjs --quality high
```

The builder measures each Kokoro narration clip, mixes them into a 60-second
track, validates every country-outline map beat, and renders:

`renders/recreations/coastline-ranking-2026-08-12.mp4`

The normal three-story daily bundle and its story history are intentionally
not changed by this recreation.
